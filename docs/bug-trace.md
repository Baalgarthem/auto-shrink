# Rastreo de Bugs (Bug Trace)

> **⚠️ REGLAS OBLIGATORIAS DE SEGUIMIENTO**
> 1. **NUNCA** se dará por cerrado (Resuelto) un bug a menos que el USUARIO lo haya validado y autorizado explícitamente.
> 2. **CUALQUIER** bug puede y debe ser reabierto si se identifica que su comportamiento persiste, ha reaparecido o es una regresión de un fallo previamente tratado.

Este documento registra de manera rigurosa los errores detectados en la herramienta para evitar retrabajos y la repetición de soluciones que ya demostraron ser ineficaces.
